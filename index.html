📊 案例研究：青少年营地活动参与度分析

项目背景

本案例模拟了一项为期两周的青少年营地活动项目。39 名参与者（涵盖 14-18 岁，不同性别与国籍）在活动开始（Week 1）和活动结束（Week 2）时，对 6 项核心活动（如城市导览、短途旅行等）进行参与度评分（1-5 分制）。

分析目标

  • • 整体趋势：Week 2 的参与度相较于 Week 1 是否有显著提升？提升幅度如何？
  • • 个体一致性：这种提升是集中于少数参与者，还是普遍存在于大多数个体中？
  • • 统计可靠性：数据是否满足配对样本 t-test 的前提假设？结论是否经得起检验？

🔬 统计验证与前提检验

在进行深入的可视化分析前，我首先对数据进行了正态性与显著性检验，以确保业务结论具有坚实的统计学支撑。

正态性检验 (Shapiro-Wilk)

为了验证参数检验的前提假设，我对每位参与者的差值分数进行了分布检验。

结果：p = 0.485 (> 0.05) 结论：差值数据符合正态分布，配对 T 检验合理。

配对样本 T 检验

对比全体参与者在 Week 1 与 Week 2 的整体均值差异，排除了随机误差的可能。

结果：t(38) = 25.49, p < 0.001 结论：两周间的参与度评分提升极显著。

整体参与度对比

关键发现：整体参与度均值从 Week 1 的 3.34 分显著提升至 Week 2 的 3.66 分，平均提升 0.32 分（+9.6%）。

误差线（均值标准误 SE）较短，结合前文极显著的 T 检验结果，充分表明该活动方案在宏观层面带来了非常稳定且显著的正向效果。

个体参与度变化轨迹

关键发现：将 39 名参与者的变化路径可视化后可见，尽管起点不同，但绝大多数个体的轨迹线均呈“一致上扬”趋势（橙线代表整体均值）。

极低的差值标准差（SD = 0.08）表明，参与者之间的提升幅度高度一致。这说明本次活动的积极影响并非偶然的个例，而是具有广泛的群体普适性。

差值正态性验证

关键发现：图中实际密度曲线（薄荷绿）与理论正态曲线（深红虚线）基本重合。

这不仅是对前文 Shapiro-Wilk 检验结果的视觉化印证，更进一步夯实了“结论可信”的方法学基础，展现了定量分析中严密的逻辑闭环。

💡 业务洞察与后续行动建议

基于上述严谨的数据验证与整体提升趋势，我进一步下钻了不同活动类型的得分差异，发现活动参与度的提升主要源于“高接触、高体验感”的活动（如城市导览、短途旅行），而非被动接受型活动（如电影之夜）。这揭示了 “沉浸式互动”是提升青少年参与意愿的核心驱动力。

🎯 针对后续活动设计的可执行建议：

    资源倾斜：增加户外探索类与高频互动类活动的时长与资源占比，最大化项目的正向收益；

  • 2

    体验重塑：对参与度长期偏低的“被动型”活动进行“互动化”改造（如将单向观看电影改为带有小组讨论或角色扮演的主题夜）；

  • 3

    精准干预：结合个体轨迹图反馈，建立预警机制——识别出 Week 1 参与度低于 2.5 分的尾部参与者，在 Week 2 开始前对其进行定向的关怀调研与激励策略介入，实现体验闭环管理。

00 / 统计检验 (正态性 & 配对 T 检验) 

# 转宽表计算差值
week_wide <- df %>%
  group_by(Participant_ID, Week) %>%
  summarise(Per_Average = mean(Engagement_Score), .groups = "drop") %>%
  pivot_wider(names_from = Week, values_from = Per_Average) %>%
  mutate(Difference = `Week 2` - `Week 1`)

# 1. 差值正态性检验 (Shapiro-Wilk)
shapiro_result <- shapiro.test(week_wide$Difference)

# 2. 参与度差异配对样本 t-test
t_result <- t.test(week_wide$`Week 2`, week_wide$`Week 1`, paired = TRUE)

01 / 整体参与度对比 (图表 1)

👉 查看图表1效果 
# 数据清洗：计算个体平均值与周汇总数据
individual_data <- df %>%
  group_by(Participant_ID, Week) %>%
  summarise(Per_Average = mean(Engagement_Score), .groups = "drop")

week_sum <- individual_data %>%
  group_by(Week) %>%
  summarise(
    Average = mean(Per_Average),
    SD = sd(Per_Average),
    n = n(),
    .groups = "drop"
  ) %>%
  mutate(SE = SD / sqrt(n))

# 图表绘制
p_col <- ggplot(week_sum, aes(x = Week, y = Average, fill = Week)) +
  geom_col(width = 0.5, alpha = 0.8) +
  geom_errorbar(aes(ymin = Average - SE, ymax = Average + SE), width = 0.5, linewidth = 0.8) +
  labs(title = "整体参与度: Week 1 vs Week 2",
       x = "时间",
       y = "平均参与度（1-5）",
       subtitle = "误差线表示均值的标准误（SE）",
       caption = paste0("平均提升：",
                       round(week_sum$Average[2]-week_sum$Average[1],2),
                       "分（",round((week_sum$Average[2]-week_sum$Average[1])/
                                   week_sum$Average[1]*100,1),"%)")) +
  scale_fill_manual(values = my_colors) +
  theme_minimal() +
  theme(plot.title = element_text(size=14,hjust=0.5),
        plot.subtitle = element_text(size=12,hjust = 0.5),
        plot.caption=element_text(size=12,hjust = 1)) +
  ylim(0, 5)
